# Astra League character art

Each character has an illustrated design sheet and a separate front-facing T-pose reference, created in the supplied cream-and-charcoal Astra League anime style.

Accent colors: orange for Armando, Cris, Isma, Mau, Tefa, speaker, Yesy, Gaby, and Andrés; pink for Rebecca; purple for Connie; green for Diego; gray for Julio; yellow for Jenny.

Julio's eyes are gently closed in both references. The three WhatsApp photos of Jenny were used as references for the same character. `speaker.png` refers to the unnamed person in an earlier WhatsApp image. Andrés is the lead singer and the three supplied Andrés images show the same person.

The 14-character selection menu is `character-select-menu.png` (2560×1440); its portraits are cropped from the main non-T-pose illustrations on the character sheets. See `PROJECT-CONTEXT.md` for the roster and continuation notes.
