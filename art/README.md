# Astra League character art

Each character has an illustrated design sheet and a separate front-facing T-pose reference, created in the supplied cream-and-charcoal Astra League anime style.

Accent colors: original team orange for Armando, Cris, Isma, Mau, Tefa, speaker, and Yesy; pink for Rebecca; purple for Connie; green for Diego; orange for Gaby; gray for Julio; yellow for Jenny.

Julio's eyes are gently closed in both references. The three WhatsApp photos of Jenny were used as references for the same character. `speaker.png` refers to the unnamed person in the earlier WhatsApp image.
