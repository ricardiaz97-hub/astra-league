# Tripo multiview reference images

Each subfolder is one creature. Upload the four PNGs from only one subfolder together in Tripo's multi-view mode:

- `regular/`: `front.png`, `left.png`, `right.png`, `back.png`
- `ranged-skinny/`: same four angles
- `huge-brawler/`: same four angles

All 12 images are PNGs with transparent backgrounds. Keep the views from one creature together; do not mix folders. The huge brawler uses a neutral A-pose with its arms separated from its body.
