# Astra League Touchdown

Shooter de arena anime 3 contra 3 que corre en el navegador. Modo Touchdown: toma el núcleo de ki del centro y llévalo a la meta rival.

- **Clases:** Impacto, Bastión, Sanador y Destello, cada una con su poder de ki.
- **Movimiento:** salto, salto en pared, dash y plataformas de salto.
- **Todo en un archivo:** `index.html` usa three.js (r128) desde cdnjs y las texturas de `textures/`.

## Cómo probarlo en tu computadora

Las texturas no cargan abriendo el archivo con doble clic. Abre una terminal en esta carpeta y ejecuta:

```
python -m http.server 8000
```

Luego entra a `http://localhost:8000`.

## Controles

WASD moverte · ratón apuntar · clic atacar · E o clic derecho poder de clase · Espacio salto · Shift dash · 1 2 3 o Q cambiar arma · R recargar · Esc o P pausa.
