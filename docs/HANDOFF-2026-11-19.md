## How we work

- **The user tests in game.** Don't play-test in the browser; make the change, run the static checks, and hand the user a short list of what to try.
- **Big changes go in one shot, then a test round.** Reference images from the user (concept art, photos) steer the design; ask for them when stuck.
- **Replies are short** (caveman style). Code comments in the game are in Spanish.
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. After code changes run `graphify update .`.

## Sewer level (ALCANTARILLAS, map index 5) — approved, polish only

- **Layout is data:** `SEWER_LAYOUT` in `index.html` (rooms and tunnels in sketch px from `art/sewers/sewer-v2-layout.svg`, scaled by `K:1.6`, y = floor height).
- **Always run** `node tools/sewer-check.js` after a layout change. It reports overlapping rooms, tunnels cutting through other rooms or too close to each other, tunnel ends outside rooms, and rooms narrower than their tunnels.
- **Builder:** `buildSewer()`.
  - Main pipes are 20 × 16 m, shortcuts 14 × 11 m.
  - A 10 m canal (6 m in shortcuts) is sunk 1.5 m between walkways and runs into every room's pool.
  - Rooms are tall with a sunken pool.
  - Joints: exact tunnel/room mouths, a rectangular opening per tunnel covered by an arch-shaped portal plate with a canal notch, plus wedge walls at angled joints.
- **Collision:** the engine only has axis-aligned boxes (`boxes`), so curves use chains of small boxes (`wline`). Walkway boxes are sized by `|nx|+|nz|` so they don't stick out over the water.
- **Water:** `WATERMAT` is a WebGL port of Renka's stylized forest water (MIT, renka-exe.itch.io), animated through `MAPFX.water`.
- **Lights:**
  - Wall lamps use the user's model `props/sewer/lamp.glb` and go through the shared 4-light pool via `MAPFX.reqs`. The pool fades lamps near the cutoff, so they don't flicker.
  - Skylights are real `SpotLight`s.
- **Opening:** you spawn at 55 m and fall into the shaft pool. The map sets `wallH:60`, and `WALLH` is per map now (default 26).
- **Textures:**
  - Walls use `textures/sewer/src/wall_moss_heavy.webp`.
  - Floors use `wall_panels_crack.webp` and `floor_plaster.webp`.
  - Trim and stains come from `textures/sewer/pack/sewer-trim-sheet.png` and `sewer-decals.png`.
  - A few Gemini textures remain: grating, corrugated tanks, hazard, glow lines.
- **Design doc:** `docs/sewer-level-v2.md` has the route, the beats and the space table (cramped to huge).

## Other work in this branch

- **Weapons:** the rifle, SMG, burst rifle and shotgun use the user's models (`props/tr_*.json`), and the blade is `props/tr_sword.json`. Menu thumbnails are `textures/ui/gun-*.png`. M338 still uses the old model, because no sniper model was provided.
- **Ricardo:** he fights bare-handed with Mixamo punches (`mx_Punching`, `mx_Combo_Punch`). Ira (X) is melee-only and swaps to `chars/ricardo-berserk.glb`. That model looks wonky because it wasn't rigged in a T-pose; the user will regenerate it. Con el corazón (E) plays the battlecry.
- **Bug fixed:** a second function named `later` (the story one) was overriding the hero one and silently broke every staged power. The story one is now `storyLater`.
- **Animations:**
  - `tools/fbx2anim.html` converts Mixamo FBX files to `anims/*.json`. It needs a small local upload listener on port 8765, which isn't in the repo.
  - `anims/aa.json` holds the Action Adventure pack clips, plus the punches and taunts.
  - Bare-handed Ricardo uses `aa_idle`, `aa_walking` and `aa_running`. Falling uses `aa_falling_idle`, and long falls use `aa_hard_landing`.
- **Look:** the Portra 400 LUT (`fx/portra400-lut.png`) and film grain are on for every map.
