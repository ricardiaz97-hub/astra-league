# Market level assets

This folder contains the low-poly assets used by the Olocuilta Market level in `index.html`.

- `kaykit-city/`: KayKit City Builder Bits models and shared texture used for street buildings, benches, and lamps. The included `KayKit_City_Builder_Bits_1.0_FREE/License.txt` is the source license.
- `kaykit-restaurant/`: KayKit Restaurant Bits produce crates and shared texture used as market stall dressing. The included `KayKit_Restaurant_Bits_1.0_FREE/License.txt` is the source license.
- `market-model/olocuilta-market.glb`: the Tripo model supplied in this project conversation, used as a market visual reference/landmark.

The map itself is a connected playable blockout: market interior and upper gallery, southern forecourt and streets, long rear fairground approach, barricade line, and Ferris wheel evacuation area. Layout follows `docs/olocuilta-market-map-guide.md` and its blockout concepts in `art/markets/`.
